# Context Hub Docs

This directory contains Context Hub-specific documentation.

- `context-hub.md`: core Context Hub domain design for knowledge, RAG, memory tiers, retrieval, freshness, governance, and P0 scope.
- `implementation-blueprint.md`: executable contracts, data models, storage layout, APIs, migration phases, tests, and acceptance checks for implementation.

Platform-wide center boundaries, cross-center protocols, reference matrix, and deployment blueprints live in the parent QuarkfanTools repository.

For a new CH session, read `../AGENTS.md`, `../STATUS.md`, `context-hub.md`, and `implementation-blueprint.md` in that order.
